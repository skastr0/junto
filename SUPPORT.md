# Support for Junto

Junto is a side project with one maintainer, not a hosted service. There is no
support email, support channel, or response-time commitment.

Report reproducible bugs, documentation corrections, and focused proposals as
[GitHub issues](https://github.com/skastr0/junto/issues). Include the version
or commit, platform, install channel, enabled experimental features, and a
minimal reproduction with private details removed.

macOS is the primary desktop platform; Linux desktop is alpha. Fleet and Remote
functionality remains experimental. Unsolicited pull requests are not accepted;
see [CONTRIBUTING.md](CONTRIBUTING.md).

For downloads, use the [official site](https://juntoagents.com/download). For a
suspected vulnerability, follow [SECURITY.md](SECURITY.md).
